# Demo Cases

`sample-api`는 `common-platform` 기능을 사람이 화면에서 점검할 수 있는 데모 페이지를 제공한다. `/demo/**`는 permit-all이며, 별도 demo profile 없이 기본 샘플에 포함된다.

## 실행 기준

- 현재/manual sample: 기본 또는 `local` profile, port `8090`
- 수동/백그라운드 테스트 슬롯: `ai` profile, port `8095~8099`, 기본 `8095`
- JUnit 통합 테스트: 고정 포트 대신 MOCK 또는 `RANDOM_PORT`

관련 정책: [260707.003.SAMPLE_PORT_POLICY.md](260707.003.SAMPLE_PORT_POLICY.md)

## 화면

| 화면 | URL | 설명 |
|---|---|---|
| 대시보드 | <http://localhost:8090/demo/index.html> | 케이스 선택, 실행, PASS/FAIL 확인 |
| 로그 뷰어 | <http://localhost:8090/demo/logs.html> | 최신 로그 파일 tail, JSON pretty print |
| 케이스 목록 | `GET /demo/cases` | UI가 렌더링하는 단일 출처 |
| OpenAPI | `/v3/api-docs`, `/swagger-ui.html` | 공통 OpenAPI 설정 확인 |
| DB 테스트 랩 | <http://localhost:8090/demo/db.html> | routing, multi tx, XA 데모 |
| 게시판 샘플 | <http://localhost:8090/demo/board.html> | JPA/jOOQ/JDBC 3-stack CRUD |
| 보안 테스트 | <http://localhost:8090/demo/security.html> | 401/403/audience/spoofing/security audit |

## 운영 메모

- UI 상단의 `X-Locale`, `X-Screen-Id`, `X-User-Id`, `Bearer` 입력으로 헤더별 동작을 확인한다.
- 보안 성공 케이스는 샘플 mock JWT를 사용한다. 실제 인증 MSA가 필요하지 않다.
- 세션과 캐시는 로컬 Redis가 떠 있고 secret이 외부 파일로 주입되어야 실제 저장/캐싱이 보인다. Redis가 없으면 해당 데모는 안내 응답을 반환한다.
- DB 데모의 현재 `ai` 프로파일 H2 경로는 전환 중 호환 경로다. 새 DB 검증 기준은 PostgreSQL이다.
- secret 값은 문서, 커밋 파일, 명령 예시에 쓰지 않는다. [260707.002.SECRET_MANAGEMENT_STANDARD.md](260707.002.SECRET_MANAGEMENT_STANDARD.md)를 따른다.
