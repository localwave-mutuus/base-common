# Platform Final Overview

`common-platform`은 실행 애플리케이션이 아니라 소비 서비스에 흡수되는 공통 라이브러리다. 핵심 산출물은 `ai.mutuus.common:common-platform` 단일 jar이며, 소비 편의를 위해 BOM과 web/batch 스타터를 함께 게시한다.

## 산출물

| 산출물 | 좌표 | 역할 |
|---|---|---|
| 공통 라이브러리 | `ai.mutuus.common:common-platform` | 추적, 로깅, 예외, i18n, 보안, 세션, 캐시, 멱등성, 영속성 감사 등 optional 자동구성 |
| BOM | `ai.mutuus.common:common-platform-bom` | 자사 아티팩트와 optional 3rd-party 버전 고정 |
| 웹 스타터 | `ai.mutuus.common:common-platform-starter-web` | lib + 표준 웹 스택 + JSON 로깅 |
| 배치 스타터 | `ai.mutuus.common:common-platform-starter-batch` | lib + 배치 친화 의존성. web/security 비전이 방지 |
| parent POM | `ai.mutuus.common:common-platform-parent` | Nexus 게시 좌표, deployAtEnd, 공통 버전의 단일 출처 |

게시처는 사내 Nexus 3이다. 현재 정본 게시 안내는 [260707.001.NEXUS_REREGISTRATION.md](260707.001.NEXUS_REREGISTRATION.md)를 따른다.

## 설계 원칙

- 라이브러리 의존성은 optional로 둔다.
- 자동구성은 `@ConditionalOnClass`, `@ConditionalOnProperty`, `@ConditionalOnMissingBean`으로 보호한다.
- 소비 서비스가 명시한 설정이 공통 기본값보다 항상 우선한다.
- 테스트는 `samples/*`에서 소비자 관점으로 검증한다.
- 고정 포트 자동 점유를 피한다. JUnit은 MOCK 또는 `RANDOM_PORT`를 우선한다.
- secret은 커밋하지 않는다. 로컬은 레포 밖 외부 secret 파일을 사용한다.

## 기능 영역

| 패키지 | 기능 | 기본값 |
|---|---|---|
| `config` | 컨벤션 기본값, app-code/instance-code 해석 | ON |
| `web` | trace/span/screen/event/user/locale 헤더 수집과 전파 | 웹 classpath에서 ON |
| `async` | ThreadLocal TraceContext 전파 | ON |
| `exception` | 표준 `ApiResponse` 오류 봉투, 네트워크 502/504 매핑 | 웹 classpath에서 ON |
| `response` | 성공 응답 자동 래핑 | opt-in |
| `openapi` | 공통 OpenAPI info와 Bearer JWT security scheme | springdoc classpath |
| `security` | 인증 위임형 OAuth2 Resource Server 기본 체인, 감사 로그, 보안 헤더 | security classpath |
| `logging` | access/payload/controller/method 로그 | access ON, 나머지 opt-in |
| `persistence` | JPA auditing과 `BaseEntity` | JPA classpath |
| `datasource` | read/write routing, multi datasource convention | opt-in |
| `session` | Redis session namespace/timeout convention | Redis Session classpath |
| `cache` | Redis CacheManager convention | opt-in |
| `idempotency` | `Idempotency-Key` 기반 재방/중복 방지 | opt-in |
| `event` | 도메인 이벤트 발행과 Modulith 연계 | ON |

## 샘플 화면

`sample-api`는 공통모듈을 사람이 직접 점검할 수 있는 `/demo/**` 화면을 포함한다.

| 화면 | URL | 검증 |
|---|---|---|
| 케이스 대시보드 | `/demo/index.html` | trace, exception, logging, security, session, cache, idempotency 등 |
| 로그 뷰어 | `/demo/logs.html` | 최신 JSON 로그 tail |
| DB 테스트 랩 | `/demo/db.html` | datasource routing, multi tx, XA 데모 |
| 게시판 샘플 | `/demo/board.html` | JPA/jOOQ/JDBC 3-stack CRUD |
| 보안 테스트 | `/demo/security.html` | 401/403, audience, spoofing, security audit |

상세 케이스 목록은 [260630.001.DEMO_CASES.md](260630.001.DEMO_CASES.md)를 본다.

## 실행 모드

| 모드 | 프로파일 | 포트 | 인프라 | URL |
|---|---|---:|---|---|
| 현재/manual sample | 기본 또는 `local` | 8090 | 로컬 PostgreSQL + Redis | `http://localhost:8090/demo/index.html` |
| 수동/백그라운드 테스트 슬롯 | `ai` | 8095~8099, 기본 8095 | 현재는 임베디드 H2. PostgreSQL-only 전환 중 | `http://localhost:8095/demo/index.html` |

`ai` 실행 예:

```powershell
.\mvnw.cmd -pl samples/sample-api spring-boot:run "-Dspring-boot.run.profiles=ai"
```

포트 정책은 [260707.003.SAMPLE_PORT_POLICY.md](260707.003.SAMPLE_PORT_POLICY.md)를 따른다. 사람이 보는 현재 샘플은 8090, 수동/백그라운드 검증은 8095~8099 범위만 사용한다.

## 로컬 인프라와 Secret

| 인프라 | 접속 | 계정/secret 정책 | 비고 |
|---|---|---|---|
| PostgreSQL | `localhost:15010` | 사용자명은 파일에 둘 수 있으나 비밀번호는 외부 secret 파일에서 import | local profile 기본 DB는 `local.test.common`; live/Aiven 기준 DB 이름은 `golmok` |
| Redis | `localhost:16010` | username 기본 `default`, password는 외부 secret 파일에서 import | 세션/캐시 데모에서만 실제 저장 확인 필요 |
| Nexus | `https://nexusrepo.local` | deployer 계정은 `~/.m2/settings.xml`, 비밀번호는 문서/커밋 금지 | self-signed CA truststore 필요 |

샘플 local profile은 `~/.mutuus/sample-api/local.yml`을 optional import한다. 이 파일은 레포 밖에 둔다. 정본은 [260707.002.SECRET_MANAGEMENT_STANDARD.md](260707.002.SECRET_MANAGEMENT_STANDARD.md)다.

## DB 정책

- 신규 DB 검증 기준은 PostgreSQL이다.
- Aiven/live 대상 DB 이름은 `golmok`이다.
- 현재 `ai` 프로파일의 H2는 과거 무인프라 데모를 위한 전환 중 호환 경로다.
- 새 테스트와 새 문서는 H2를 기준으로 추가하지 않는다.
- jOOQ codegen은 기본 빌드에서 DB 연결을 열지 않고, 명시적 `pg-codegen` 프로파일로 PostgreSQL metadata에서 수행한다.

정본은 [260706.002.POSTGRES_ONLY_MIGRATION_CONTEXT.md](260706.002.POSTGRES_ONLY_MIGRATION_CONTEXT.md)다.

## 검증 명령

포트를 열지 않는 기본 검증:

```powershell
.\mvnw.cmd -pl samples/sample-api -am test-compile
.\mvnw.cmd -pl samples/sample-batch -am test
```

샘플 프로퍼티와 포트 정책 검증:

```powershell
.\mvnw.cmd -pl samples/sample-api -Dtest=AiProfilePropertiesTest,SamplePortPolicyTest test
```

배포 전 검증/게시:

```powershell
$env:MAVEN_OPTS='-Djavax.net.ssl.trustStore=C:\Users\cvnra\.m2\nexus-local-ca-truststore.p12 -Djavax.net.ssl.trustStorePassword=changeit -Djavax.net.ssl.trustStoreType=PKCS12'
.\mvnw.cmd clean deploy
```
