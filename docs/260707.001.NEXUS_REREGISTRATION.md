```xml

  <repository>
    <id>nexus-releases</id>
```

PKCS12 truststore.

- Certificate: `C:\Users\cvnra\wsl-gateway\nexus-local-ca.crt`

- Alias: `nexus-local-ca`

Use this `MAVEN_OPTS` value for deploy or any Maven command that reaches Nexus:


## Notes

- The previous temporary truststore based on the leaf certificate was replaced
  by a CA-based truststore for this Maven workflow.
- The repository-level Maven mirror means dependency resolution now goes through
  `maven-public`. If Nexus is unavailable, Maven resolution can fail even when
  Maven Central is available.
- Importing the CA into the JDK global `cacerts` was intentionally not done here;
  this keeps the change local to Maven commands that opt into the truststore.
