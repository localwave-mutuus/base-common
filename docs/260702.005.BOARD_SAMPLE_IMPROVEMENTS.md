# Board Sample Improvements

`sample-api`의 board 샘플은 JPA, jOOQ, Spring Data JDBC 세 스택을 같은 도메인에 적용해 소비 서비스가 공통모듈을 어떻게 써야 하는지 보여주는 참조 구현이다.

기본 패턴은 다음과 같다.

- Controller -> Service -> Repository/DAO
- record DTO + MapStruct + Bean Validation
- `ApiResponse` / `PageResponse`
- 도메인 `ErrorCode` + `BusinessException`
- Flyway schema + Hibernate `ddl-auto=validate`

## 완료된 개선

| 항목 | 현재 기준 |
|---|---|
| 테스트 보강 | 3-stack CRUD, 검색/페이징, validation, optimistic locking, cascade delete 검증 |
| 스키마 관리 | Flyway migration + `ddl-auto=validate` |
| 페이징 방어 | page/size 정규화와 상한 |
| jOOQ insert 방어 | null/NPE 대신 명확한 도메인 오류 |
| LIKE 검색 | wildcard escape |
| 낙관적 잠금 | `version` 컬럼, JPA/JDBC/jOOQ 각각 409 변환 |
| cascade delete | Flyway V3로 FK `on delete cascade` 반영 |
| jOOQ codegen | 체크인된 생성 소스를 기본 빌드에서 컴파일, 재생성은 `pg-codegen` 프로파일 |

## 현재 정책 변경

과거 문서는 H2와 PostgreSQL 공통 DDL을 강조했지만, 현행 DB 기준은 PostgreSQL이다. H2는 `ai` 프로파일의 무인프라 데모 호환을 위해 남아 있는 전환 중 경로일 뿐 새 기준이 아니다.

따라서 앞으로 board 샘플 개선은 다음 원칙을 따른다.

1. 새 DB 테스트는 H2가 아니라 PostgreSQL Testcontainers 또는 live opt-in PostgreSQL을 사용한다.
2. 기본 Maven 빌드는 jOOQ codegen을 실행하지 않는다.
3. jOOQ 생성 소스가 필요할 때만 `pg-codegen` 프로파일을 켜고 PostgreSQL metadata에서 생성한다.
4. live/Aiven 대상 DB 이름은 `golmok`이다.
5. secret은 SOPS + age 외부 파일 또는 CI/CD secret store로 주입한다.

정본 DB 전환 문서: [260706.002.POSTGRES_ONLY_MIGRATION_CONTEXT.md](260706.002.POSTGRES_ONLY_MIGRATION_CONTEXT.md)

## 남은 개선 후보

| 우선순위 | 항목 | 방향 |
|---|---|---|
| P1 | PostgreSQL-only 테스트 전환 | 기존 H2 통합 테스트를 PostgreSQL Testcontainers/live opt-in으로 대체 |
| P1 | `ai` profile DB 전환 | 임베디드 H2 대신 PostgreSQL opt-in 또는 별도 `pg` profile로 전환 |
| P2 | OpenAPI 문서 보강 | `@Tag`, `@Operation`, `@Schema`로 샘플 API 설명 추가 |
| P2 | DTO 표현 정리 | demo용 `tech` 표시는 도메인 응답과 분리 |
| P3 | multi schema | `board` schema 소유권을 Flyway와 jOOQ codegen에 명확히 반영 |

## 검증 기준

포트를 열지 않는 기본 검증:

```powershell
.\mvnw.cmd -pl samples/sample-api -am test-compile
```

board 관련 테스트만 실행할 때는 루트 reactor에서 실행해 방금 빌드한 공통모듈을 사용한다.

```powershell
.\mvnw.cmd -pl samples/sample-api -Dtest=*Board* test
```

수동 화면 검증은 현재 샘플 포트 8090에서 수행한다.

```text
http://localhost:8090/demo/board.html
```
