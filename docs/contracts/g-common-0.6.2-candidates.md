# [REQ-261021-02] G-COMMON 0.6.2 후보 목록

**상태: A05 계약 검토 후속 후보(미합의·미구현·미발행).**

P00 결정 기준 **C1·C2는 완료**(base-common `0d532f4`, INFRA `532d1e8`)다. 아래는 이후 C3 보강을 위한 0.6.2 후보이며 현재 완료 범위에 포함하지 않는다. 입력 문서의 ‘C2 전체 미완료·A05 검토 전’은 해당 문서 작성 시점의 상태로 구분하며, 후보별 합의·구현 완료 근거로 사용하지 않는다.

근거: [계약](g-common-trace-log-contract.md)의 절 번호, [C2 현황](../reports/g-common-c2-1-status.md)의 표 항목, 이번 brief의 P00 결정. 기존 완료 전용 관측을 수신 성공이나 미관측 원인 확정으로 해석하지 않는다.

**진행 관문(P00):** 현재 C5 회원은 **0.6.1로 진행 중**이다. **C5 회원 → C6 앱/배치 dev 실측 후, C7과 함께 C3의 0.6.2 보강을 한 번에 진행**한다. 후보 문서 작성으로 구현·발행을 승인하지 않는다. **C4 BO는 중지 해제 전 waiting**이며 재개하지 않는다.

**C7 연계 선행조건(A17):** 계약 §6.2·§6.5 및 현황 ‘매핑·지연’에 따라 v5 신규 4필드의 explicit template·rollover 수용, 동일 문서의 발생시각과 `event.ingested` 보존·연결을 별도로 확보한다. 실제 적용 템플릿은 입력에서 미확보이며 적재 지연은 계산 불가 상태다. 필드·템플릿·적재 지연/용량/보관 측정은 C7 범위로 구별하고 공통 코드 구현 완료와 섞지 않는다. 새 측정값·개인/좌석 배정은 추가하지 않는다.
