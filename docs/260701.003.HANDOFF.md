# Handoff - common-platform

이 문서는 `common-platform`의 현재 작업 기준을 다음 작업자에게 넘기기 위한 정본 메모다.

## 프로젝트 요약

- 핵심 산출물은 단일 jar 공통 라이브러리 `ai.mutuus.common:common-platform`이다.
- Maven reactor 구조:
  - `parent/`: 게시 모듈 공용 parent POM, Nexus distributionManagement, deployAtEnd 정책
  - `bom/`: `common-platform-bom`
  - `lib/`: 공통 라이브러리
  - `starters/starter-web`, `starters/starter-batch`: 소비자용 큐레이션 스타터
  - `samples/sample-api`, `samples/sample-batch`: 소비 검증 샘플
- 기준 런타임은 Java 21 / Spring Boot 4.1.0 / Spring Modulith 2.1.0이다.
- 테스트는 원칙적으로 `samples/*`에서 수행한다. `lib`는 optional 의존성과 자동구성 조건을 지키는 라이브러리다.

## 현재 실행 모드

| 목적 | 프로파일 | 포트 | 인프라 | 비고 |
|---|---|---:|---|---|
| 사람 개발/디버그 | 기본 또는 `local` | 8090 | 로컬 PostgreSQL 15010, Redis 16010 | 현재 샘플 화면 |
| 수동/백그라운드 검증 | `ai` | 8095~8099, 기본 8095 | 현재는 임베디드 H2 | 전환 중. 새 DB 검증은 PostgreSQL 기준 |
| JUnit 통합 테스트 | test context | `RANDOM_PORT` 또는 MOCK | Testcontainers/live opt-in만 | 고정 포트 자동 점유 금지 |

자세한 포트 규칙은 [260707.003.SAMPLE_PORT_POLICY.md](260707.003.SAMPLE_PORT_POLICY.md)를 따른다.

## 게시 기준

게시 대상은 사내 Nexus 3이다.

- releases: `https://nexusrepo.local/repository/maven-releases/`
- snapshots: `https://nexusrepo.local/repository/maven-snapshots/`
- repository id: `nexus-releases`, `nexus-snapshots`
- 자격증명: `~/.m2/settings.xml`의 deployer 계정
- 인증서: Maven 전용 truststore를 `MAVEN_OPTS`로 지정

배포 명령:

```powershell
$env:MAVEN_OPTS='-Djavax.net.ssl.trustStore=C:\Users\cvnra\.m2\nexus-local-ca-truststore.p12 -Djavax.net.ssl.trustStorePassword=changeit -Djavax.net.ssl.trustStoreType=PKCS12'
.\mvnw.cmd clean deploy
```

상세는 [260707.001.NEXUS_REREGISTRATION.md](260707.001.NEXUS_REREGISTRATION.md)를 본다. 과거 패키지 저장소 안내는 현재 정본 게시처가 아니다.

## Secret 기준

- 커밋 파일에 DB/Redis/Nexus/admin 비밀번호를 두지 않는다.
- `samples/sample-api/src/main/resources/application-local.yml`의 비밀번호는 비워 두고, `spring.config.import`로 외부 파일을 읽는다.
- 로컬 개발 secret은 `~/.mutuus/<service>/local.yml`처럼 레포 밖 외부 파일에 둔다.
- 공통모듈은 secret manager client 런타임 의존성을 직접 갖지 않는다.
- 공통모듈은 위험한 설정을 감사/경고하고, 소비 서비스가 안전한 외부 설정 방식을 쓰도록 샘플과 문서로 안내한다.

정본은 [260707.002.SECRET_MANAGEMENT_STANDARD.md](260707.002.SECRET_MANAGEMENT_STANDARD.md)다.

## DB 기준

- 신규 DB 검증 기준은 PostgreSQL이다.
- Aiven/live 대상 DB 이름은 `golmok`이다.
- 기존 H2 기반 `ai` 프로파일과 일부 테스트는 전환 중 호환 경로다.
- 새 테스트와 새 문서는 H2를 기준으로 추가하지 않는다.
- jOOQ codegen은 기본 빌드에서 DB 연결을 열지 않고, 필요 시 `pg-codegen` 프로파일로 PostgreSQL metadata에서 생성한다.

정본은 [260706.002.POSTGRES_ONLY_MIGRATION_CONTEXT.md](260706.002.POSTGRES_ONLY_MIGRATION_CONTEXT.md)다.

## 검증 명령

포트를 열지 않는 기본 검증:

```powershell
.\mvnw.cmd -pl samples/sample-api -am test-compile
.\mvnw.cmd -pl samples/sample-batch -am test
```

문서/설정 변경 후 샘플 프로퍼티만 확인할 때:

```powershell
.\mvnw.cmd -pl samples/sample-api -Dtest=AiProfilePropertiesTest,SamplePortPolicyTest test
```

전체 배포 전에는 루트에서 `.\mvnw.cmd clean deploy`를 실행한다. 이 명령은 샘플 테스트까지 성공한 뒤 deployAtEnd로 parent/bom/lib/starters를 게시한다.

## 남은 주의점

- H2 제거는 단계적으로 진행한다. 제거 전에는 `application-ai.yml`, `DbDemoSupport`, H2 의존성, H2 테스트를 PostgreSQL 대체 경로로 바꿔야 한다.
- live PostgreSQL/Redis 테스트는 반드시 접속 가능성과 자격증명 인증을 확인한 뒤 opt-in으로만 수행한다.
- 문서에 평문 비밀번호나 과거 내부 계정명을 다시 넣지 않는다.
